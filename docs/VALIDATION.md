Сквозные сценарии: анонимный/чужой доступ; пределы класса руководителя; создание аккаунта и обязательная смена пароля; сохранение/продолжение, конфликт версий и запрет завершения неполного теста; видимость комментариев и Excel-экспорт; проверка CSV и повторного импорта; полный пользовательский путь ученика по 36 вопросам с скачиванием PDF; приватные материалы, посещаемость и обратная связь; администратор, другая организация, остановка подписки и отзыв заблокированной сессии.

PostgreSQL-миграция исполнялась в PGlite. Проверены запрет прямого доступа для anon/authenticated, права service_role, ожидаемые ревизии, rollback при конфликте, межорганизационные ссылки и уникальность логина. Подключение к удалённому Supabase, внешний деплой, нагрузочная проверка и юридическая/психометрическая экспертиза не выполнялись. По выбору владельца используется локальное демо.

Известные границы первой версии перечислены в README. Полная спецификация — целевой документ и не является утверждением, что все её расширенные функции уже реализованы.

## Проверка подготовки Netlify

- Добавлен адаптер Netlify Blobs с strong consistency и условной атомарной записью демобазы по ETag. Локальная SQLite продолжает работать.
- `npm run test:netlify`: 4 проверки пройдены на официальном локальном эмуляторе. Учтено документированное в тестах отсутствие ETag в GET эмулятора 11.1.7; для условного PUT используется его настоящий ETag из LIST.
- После изменений повторены TypeScript, ESLint, 20 основных тестов и 9 браузерных сценариев — успешно.
- `netlify-cli@27.16.2 build --offline`: успешно, адаптер Next.js Runtime 5.16.5 упаковал серверную функцию. Предупреждение о невозможности получить свежий список плагинов в offline-режиме не отменяет использование закреплённой версии.
- Netlify CLI сообщает, что вход в аккаунт не выполнен. Публикация реального сайта и проверка URL `*.netlify.app` не проводились без авторизации владельца. Ссылка в README открывает мастер развёртывания, а не готовый сайт.

## Упрощённый локальный запуск

Добавлена команда `npm run local` и файлы запуска для Windows/macOS. На Linux проверены запуск на отдельном порту, HTTP-страница, демовход и собственные данные SQLite. Отдельно проверена чистая копия проекта в каталоге с пробелами без `node_modules`: команда самостоятельно выполнила `npm ci`, запустила приложение, создала демобазу и успешно обслужила вход/чтение 100 профессий. Windows/macOS-обёртки в этой Linux-среде не запускались. После изменений прошли ESLint и TypeScript.
